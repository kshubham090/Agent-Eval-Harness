# Benchmark artifacts

- [latest.json](latest.json): raw offline harness benchmark measurements and
  provenance. [latest.md](latest.md) renders the same results as tables.
- [agent_smoke.jsonl](agent_smoke.jsonl): 16 authored prompt-only smoke tasks
  across Python tracing, data transformation, algorithms and constraints.
  Reference answers are generated by [generate_smoke.py](generate_smoke.py).

The two suites serve different purposes. `scripts/benchmark.py` measures
deterministic harness operations without any model or network calls. The smoke
dataset can be sent to your existing agent to test its integration and inspect
basic output behavior. No live agent results for that dataset are included.

Every smoke case asks for a JSON value. Use `--scorers json` to compare parsed
JSON independently of whitespace or object-key order. Array order, types and
values still matter; Markdown-wrapped output does not satisfy the contract.

```sh
agent-eval eval --dataset benchmarks/agent_smoke.jsonl --agent codex \
  --scorers json --concurrency 1 --runs 3 --output results/codex-smoke.json

agent-eval eval --dataset benchmarks/agent_smoke.jsonl --agent claude-code \
  --scorers json --concurrency 1 --runs 3 --output results/claude-smoke.json
```

Those commands require the relevant CLI to be installed and authenticated and
may incur provider charges. The smoke prompts need no filesystem changes.
The harness uses each adapter's configured agent permissions.

These small, public, prompt-only examples are not held-out research data or a
coding-agent leaderboard. They do not evaluate repository edits, tool-use
reliability, long tasks or production readiness. Replace or extend them with
your own tasks before making deployment decisions. Do not tune a prompt on
this suite and then present its score as an independent evaluation.

Regenerate the exact references with `python benchmarks/generate_smoke.py`.
For offline performance reproduction and historical baseline limitations,
read [the methodology](../docs/benchmarking.md).
